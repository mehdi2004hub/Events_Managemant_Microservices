## 🎯 Vue d'ensemble

Events Management Microservices est une solution scalable et modulaire pour gérer des événements. La plateforme utilise une architecture microservices pour garantir une flexibilité, une maintenabilité et une scalabilité optimales.

**Caractéristiques principales :**
- ✅ Gestion complète des événements
- ✅ Interface utilisateur réactive et moderne
- ✅ Architecture microservices découplée
- ✅ Type-safe avec TypeScript
- ✅ Scalabilité horizontale

## 🛠️ Technologies utilisées

### Frontend (51.3%)
| Technologie | Description |
|---|---|
| **React 18.3** | Framework UI déclaratif pour construire des interfaces utilisateur dynamiques et réactives |
| **TypeScript 5.6** | Langage typé qui s'exécute sur JavaScript, améliorant la qualité et la maintenabilité du code |
| **Vite 5.4** | Build tool ultra-rapide et un serveur de développement moderne pour React |
| **Tailwind CSS 3.4** | Framework CSS utilitaire pour un design responsive et moderne sans quitter le HTML |
| **React Router 6.30** | Gestionnaire de routage client-side pour une navigation fluide et des applications SPA |
| **Zustand 5.0** | Gestionnaire d'état léger et simple pour la gestion centralisée de l'état global |
| **Axios 1.15** | Client HTTP populaire pour les requêtes API asynchrones |
| **Framer Motion 12.38** | Bibliothèque d'animation puissante pour des animations fluides et intuitives |
| **Lucide React 1.8** | Bibliothèque d'icônes SVG modernes et extensibles pour React |

### Backend (43.7%)
| Technologie | Description |
|---|---|
| **Python** | Langage de programmation puissant et flexible pour les microservices backend |
| **FastAPI / Django** | Frameworks web modernes pour construire des APIs REST robustes |
| **PostgreSQL / MongoDB** | Bases de données pour la persistance des données d'événements |

### Autres technologies
| Technologie | Description |
|---|---|
| **CSS (2.6%)** | Styling custom pour les besoins spécifiques de design |
